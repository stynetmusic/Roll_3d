# Roll_3d

Офлайн-калькулятор сметы рольставенного шкафа: окно с 3D-моделью роллеты, прайс из файлов ПГИ и сметы в локальной базе. Позиции выбираются из прайса вручную. Программа рассчитана на Windows 10 и Windows 11, 64-bit.

## Что нужно для сборки

Сборку запускайте на Windows 10 или 11, 64-bit. Готовый файл тоже будет 64-bit.

1. Откройте [python.org/downloads/windows](https://www.python.org/downloads/windows/).
2. Скачайте **Windows installer (64-bit)** для Python 3. Подойдёт 3.11 или 3.12.
3. Запустите установщик. Внизу первого окна включите **Add python.exe to PATH**, затем **Install Now**.
4. Закройте установщик и откройте новое окно командной строки. Проверка:

```
py -3 --version
py -3 -c "import struct; print(struct.calcsize('P') * 8)"
```

Вторая команда должна напечатать `64`. Если `py` не находится, переустановите Python с включённым PATH и снова откройте командную строку.

## Один файл Roll_3d.exe

В командной строке перейдите в папку, где лежат `Roll_3d.py`, `requirements.txt` и каталог `web`. Кавычки вокруг `web;web` обязательны и в cmd, и в PowerShell.

```
py -3 -m pip install -r requirements.txt
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --noconfirm --clean --onefile --windowed --name Roll_3d --add-data "web;web" Roll_3d.py
```

Готовый файл: `dist\Roll_3d.exe`. Это один переносимый файл. На компьютере, где им пользуются, Python ставить не нужно и папку с библиотеками копировать не нужно. Каталоги `build` и `dist` и файл спецификации, которые создаёт PyInstaller, заказчику не нужны — достаточно exe.

Перед сборкой программу можно открыть из исходников:

```
py -3 Roll_3d.py
```

Окно рисует компонент Windows **WebView2**. В Windows 11 он уже есть. В Windows 10 он обычно установлен вместе с Microsoft Edge. Это часть системы, не среда Python. Если exe сразу закрывается, поставьте [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) и для диагностики соберите ту же команду без `--windowed`: текст ошибки останется в консоли. Подробности также пишутся в `data\roll_3d.log`.

## Первый запуск и база

Положите `Roll_3d.exe` в одну папку с файлами:

- `ПГИ-06-12-2024.xlsx` — импортируется и становится активным прайсом
- `ПГИ-16.09.2024.xlsx` — импортируется, не активный
- `ПГИ-16.09.2024-42.xlsx` — импортируется, не активный

`Test.xlsx` программа не читает. Другие файлы ПГИ добавляются кнопкой **Импорт xlsx** на экране «Прайс».

При первом запуске рядом с exe создаётся `data\roll_3d.sqlite`. В ней прайсы, ваши цены, подписи единиц и сметы. Чтобы перенести программу на другой компьютер, скопируйте `Roll_3d.exe` и папку `data`. Если база уже есть, повторный первый импорт сам не запускается: новые файлы добавляйте кнопкой импорта.

Повторный импорт того же имени файла обновляет цену из файла, имя, цвет и единицу. Цену, которую правили вручную, он не затирает. Кнопка **Заменить мои цены ценами из файла** снимает ручные правки со всего открытого прайса. **К цене файла** делает то же с одной позицией.

Цена 0 импортируется и в поиске скрыта. Её показывает переключатель **показывать без цены**.

## Как считать смету

Слева шкаф с роллетой: короб, полотно, левая и правая направляющие, вал, привод, концевой профиль, крышки. Левая кнопка мыши вращает модель, колесо меняет масштаб, клик подсвечивает деталь и открывает поиск активного прайса по группе. Артикул клик не подставляет: в поиске выбирают код и цвет, задают количество и нажимают **В смету**. Тот же поиск открывается кнопкой **Добавить позицию** и клавишей Ctrl+F.

Группы по умолчанию, их меняют в настройках:

| Деталь | Префикс имени |
| --- | --- |
| Короб | SB |
| Полотно | AR |
| Направляющая | GR |
| Вал | RT |
| Привод | AM |
| Концевой профиль | ES |
| Крышки | SF |

Префикс сравнивается с началом имени. `SB` находит `SB-QR/137`.

Строка сметы: код, имя, цвет, единица, ширина мм, высота мм, количество, цена, скидка строки %, сумма. Ширина и высота в деньги не входят. Цена берётся из прайса в момент добавления и дальше меняется только в этой строке. Правка прайса не меняет уже сохранённые заказы.

Сумма строки = количество × цена × (1 − скидка строки / 100).  
Итог = сумма строк × (1 − скидка заказа / 100).  
Скидки по умолчанию 0.

Шапка заказа: номер, дата, клиент, объект, комментарий, скидка на заказ %. Кнопки: новая смета, открыть, сохранить, дублировать, экспорт в xlsx.

Клавиши: Ctrl+N — новая смета, Ctrl+S — сохранить, Ctrl+F — поиск, Delete — удалить выбранную строку сметы.

Единицы в файле ПГИ имеют коды 0, 2, 3 и 4. Подписи по умолчанию: «ед. 0», «ед. 2», «ед. 3», «ед. 4». Их переименовывают в настройках.
